# 1. Phase 3C Objective

The purpose of Phase 3C is:

> **Allow multiple agents to perform real repository modifications safely and independently, with explicit isolation, artifact tracking, review, and controlled integration.**

The fundamental problem is:

```text
Without isolation:

Claude ─┐
Codex  ├──→ same working directory
Pi     ┘
```

This is unsafe.

The desired model is:

```text
Repository
   │
   ├── Worktree A → Task A → Agent A
   │
   ├── Worktree B → Task B → Agent B
   │
   ├── Worktree C → Task C → Agent C
   │
   └── Worktree D → Task D → Agent D
```

The user reviews the resulting artifacts and chooses what gets integrated.

---

# 2. Core Principle

The TaskScheduler must never assume that all tasks operate in the same directory.

Each task must have an explicit execution environment.

Conceptually:

```text id="oh8v3g"
Task
 └── ExecutionEnvironment
      ├── cwd
      ├── worktree
      ├── branch
      ├── isolation
      └── permissions
```
