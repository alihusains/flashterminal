## Real-Agent Validation + Concurrency + Desktop Agent UX + Event Streaming

Phase 2B implementation is complete at the code/architecture level.

The current system includes:

* ExecutionId / ExecutionKind
* AgentSession
* AgentRuntime
* AgentRegistry
* AgentAdapter
* Generic CLI adapter
* Claude adapter
* Codex adapter
* OpenCode adapter
* Pi adapter
* Fake agent
* shared PTY architecture
* provider registry
* model abstraction
* Keychain-backed credentials
* redaction
* agent pane creation
* agent persistence
* agent CLI
* agent IPC
* unified ApplicationEvent model
* fairness-aware event draining

Current automated gates:

```text
cargo test --workspace          163/163
cargo clippy --all-targets      0 warnings
cargo fmt --check               clean
cargo build --release           OK
```

This phase is NOT about adding new agent architecture.

It is about validating and finishing Phase 2B.

Do NOT implement multi-agent orchestration yet.

Do NOT implement task graphs.

Do NOT implement agent teams.

# 27. Event Backpressure

IPC event streaming must not be able to block or slow the main application.

A slow IPC client must not cause:

```text
AgentRuntime
↓
blocked
```

Use bounded subscriber queues.

Define:

```text
slow client
```

behavior explicitly:

```text
drop non-critical events
coalesce state events
disconnect client
```

Do not allow event streaming to compromise terminal performance.
